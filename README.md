# TeamFlow React + Vite

## 실행
```bash
npm install
npm run dev
```

## 빌드
```bash
npm run build
```

## 현재 기능
- 대시보드
- 업무 등록/수정/삭제
- 회의록 편집
- 일정 등록
- 관리자 카테고리 추가/삭제
- 캐릭터 아바타
- localStorage 저장

## 추후 연동
- Supabase Auth / DB / Realtime
- Google Calendar API
- Vercel 배포

## GitHub Pages 배포 시
Vite 설정과 GitHub Actions를 추가하거나, Vercel 배포를 권장합니다.
